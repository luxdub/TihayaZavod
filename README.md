# Тихая заводь — Unity, этап 2 (окружение)

## Что это
Это исходный Unity-проект с игровым кодом, а не готовый APK. Проект рассчитан на Unity 2022.3 LTS или новее. Он не является копией Russian Fishing 4: используются собственное название и процедурные временные модели.

## Что есть в проекте
- Вид от первого лица и мобильное управление касаниями.
- Заброс, ожидание поклёвки, подсечка и вываживание с натяжением лески и фрикционом.
- Несколько видов рыб, наживки, удилища, магазин, сумка, журнал и сохранения.
- Смена дня и ночи.
- **Новое в этапе 2:** процедурно созданный берег озера, две линии деревьев, дальний берег, камни, кусты, трава и камыши; случайная вариация размеров и положения, чтобы локация не выглядела как пустая плоскость.

## Как открыть
1. На компьютере установите Unity Hub и Unity 2022.3 LTS.
2. Создайте 3D-проект и скопируйте папку `Assets/Scripts` из этого архива в папку `Assets` проекта.
3. Откройте пустую сцену и нажмите Play: Bootstrap создаёт тестовую локацию автоматически.
4. Для Android выберите Android Build Support, включите Landscape и соберите APK через Build Settings / Build Profiles.

## Важно
- Код в этом проекте ещё не проверен запуском в Unity Editor в этой среде.
- Модели деревьев, рыб, рук и снастей пока процедурные/примитивные. Это следующий большой этап: заменить временные модели на качественные 3D-ассеты и добавить более детальную воду.
- На одном телефоне открыть ZIP и сразу установить APK нельзя: сначала проект должен быть собран Unity на компьютере или в подходящей облачной среде.
